# Archive data

قاعدة الأرشيف لا تُحفظ داخل Git.

ضع أحد الملفين وقت النشر:

- `data/nawafith_internal.sqlite3.zst` — النسخة المضغوطة، ويتم فكها تلقائياً أثناء `npm install`.
- أو `data/nawafith_internal.sqlite3` — قاعدة SQLite الجاهزة مباشرة.

يمكن أيضاً تعيين `ARCHIVE_URL` إلى رابط دائم للملف المضغوط حتى يقوم `scripts/prepare-archive.js` بتنزيله وتجهيزه أثناء البناء.

الأرشيف المعتمد تم التحقق منه ويحتوي على:

- 53,547 صفحة محفوظة.
- 17,400 سجل منظم.
- 26,872 صفحة عربية.

لا تضع كلمات مرور أو ملفات `.env` داخل هذا المجلد.
